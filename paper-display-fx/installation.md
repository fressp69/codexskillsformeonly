# Install paper-display-fx

Copy the entire paper-display-fx folder with SKILL.md directly inside it. When updating an installation, merge the contents into the existing folder of that name. Keep one active copy per chosen scope.

| Client | Personal | Project | Invoke |
|---|---|---|---|
| Codex | ~/.agents/skills/paper-display-fx | .agents/skills/paper-display-fx | $paper-display-fx |
| Claude Code | ~/.claude/skills/paper-display-fx | .claude/skills/paper-display-fx | /paper-display-fx |

On Windows, ~ is the user profile. This package has no plugin dependency, installer script or required resource pack. Start a new session in the intended project and invoke the skill with a brief, for example “Design a retractable four-arm scanner. Read the sensor pattern and derive the scan origin from its moving lens.”
